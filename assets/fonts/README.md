# Project Fonts

## 문화재돌봄체

- 용도: 최종 영상 자막
- 기본 파일: `culture-heritage-care/문화재돌봄체 Bold.ttf`
- 실제 패밀리명: `MunhwajaeDolbom Bold`
- 공식 배포: https://chdolbom.org/wp/발간물/?mod=document&pageid=1&uid=759
- 출처: 국가유산돌봄사업(구 문화재돌봄사업) 공식 배포 첨부파일

## Pretendard

- 용도: INFO 라벨, 숫자, 단위
- 라벨: `Pretendard SemiBold`
- 숫자·단위·강조: `Pretendard Bold`
- 버전: 1.3.9
- 공식 배포: https://github.com/orioncactus/pretendard/releases/tag/v1.3.9
- 라이선스: SIL Open Font License 1.1 (`pretendard/LICENSE.txt`)

런타임은 한글 글리프가 포함된 `Pretendard-SemiBold.otf`, `Pretendard-Bold.otf`를 사용한다. `PretendardStd` 파일은 라틴 글리프 위주의 서브셋이라 한글 INFO 렌더링에 사용하지 않는다.
