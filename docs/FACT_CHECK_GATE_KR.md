# 사실 검증 게이트

## 원칙

검증되지 않으면 만들지 않는다. AI의 자신감 점수만으로 PASS를 결정하지 않고 주장, 근거, 출처의 연결을 확인한다.

## 실행 순서

```text
후보 주제
-> 핵심 주장 분해
-> 기본 출처 수집
-> 주장별 근거 문장 검색
-> 1차 판정
-> HOLD인 경우 독립 출처 보강
-> 2차 판정
-> PASS / HOLD / REJECT
```

보강 검색과 2차 판정 뒤에도 근거가 부족하면 자동 실행을 종료한다. 같은 입력으로 무제한 재검증하지 않는다. PASS 뒤 대본 전에는 공식 사진·시공 사진·도면·단면의 URL 또는 유효 PDF 페이지와 설명을 가진 실제 제작 참조를 다시 확인한다. 가려진 내부·매립·수중 상태는 단면 또는 시공 근거가 없으면 `needs_reference`로 보류한다. production canary는 사실 검증 전에 NASA 공식 HTTPS 자료의 redirect 최종 URL, MIME·signature·decode 또는 PDF page, cache hash, license, 서로 다른 CLEAN 상태를 preflight로 확인하고, 검증된 reference allowlist 밖 근거는 HOLD한다. canary는 CLEAN/INFO 검토까지만 진행하며 H3·영상 큐는 허용하지 않는다. 이 선제 게이트와 production brief 독립 검토, evidence packet·호출 계측, 저장 산출물 기반 회귀 보고는 구현되어 있다. 실제 이미지·영상 재생성이나 외부 OCR 기반 검증은 이번 범위에 포함하지 않는다.

## 주장 판정

```text
SUPPORTED
허용된 출처의 근거가 주장을 직접 뒷받침한다.

REFUTED
신뢰 가능한 근거가 주장을 직접 반박한다.

NOT_ENOUGH_INFO
관련 자료는 있지만 주장을 확정하거나 반박하기에 부족하다.
```

## 주제 판정

### PASS

- 모든 핵심 주장이 SUPPORTED다.
- 핵심 주장에 Tier A 출처가 하나 이상 연결된다.
- 가능한 경우 1차 기록과 독립된 전문 해설을 함께 확보한다.
- 연도, 인물, 장소, 사건 순서가 충돌하지 않는다.
- 대본에 사용할 인과관계가 근거 범위를 넘지 않는다.
- 신뢰도는 75 이상이다.

### HOLD

- 핵심 주장 중 NOT_ENOUGH_INFO가 있다.
- 출처는 있으나 서로 독립적이지 않다.
- 해석이 논쟁 중이거나 원인과 결과를 단정하기 어렵다.
- 영상 재현이 사실보다 강한 인상을 만들 위험이 있다.

### REJECT

- 핵심 주장이 REFUTED다.
- 후보의 흥미 요소가 잘못된 정보에 의존한다.
- 허용되지 않은 출처 외에는 근거가 없다.
- 쇼츠 분량으로 줄일 때 핵심 의미가 뒤집힌다.

## 역사 출처 우선순위

```text
Tier A: 조선왕조실록, 한국사데이터베이스, 국가기록원, 국가유산청 등 공식 기록
Tier B: 한국민족문화대백과사전, 국공립 박물관과 연구기관의 전문 해설
Tier C: 대학, 학술 논문, 전문 출판물
Discovery only: Wikipedia, 언론, 블로그, 커뮤니티
```

Discovery only 출처는 검색어와 후보 발굴에는 사용할 수 있지만 단독으로 PASS 근거가 될 수 없다.

## 저장 항목

주제 판정뿐 아니라 다음 정보를 보존한다.

```text
원자 주장
주장 판정
근거 문장 또는 짧은 근거 구간
출처 제목과 URL
발행 기관
출처 등급
무엇을 확인했는지
수집 시각
내용 hash
충돌 자료
영상적 단순화 주의점
```

## 재검증과 하위 산출물

PASS 주제를 다시 검증하면 기존 대본, TTS와 장면표를 즉시 삭제하지 않고 `stale` 처리한다. 새 검증과 새 대본이 승인되기 전에는 기존 미디어를 새 사실 기준의 결과로 표시하지 않는다.
