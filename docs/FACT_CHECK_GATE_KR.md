# 사실 검증 게이트

## 목적

쇼츠 제작 전에 핵심 사실이 확인되지 않는 주제를 걸러낸다. 이 단계는 대본보다 먼저 실행하며, 통과하지 못한 주제는 이미지와 영상 단계로 보내지 않는다.

## 판정

```text
PASS
핵심 주장, 연도, 인물, 장소, 원인과 결과가 신뢰 가능한 자료로 확인됨.

HOLD
흥미로운 주제지만 핵심 근거가 부족하거나 자료가 서로 충돌함. 추가 조사 필요.

REJECT
핵심 주장이 틀렸거나 출처가 약함. 또는 쇼츠로 만들 때 사실 왜곡이 커짐.
```

## 체크리스트

- 이 주제의 핵심 주장은 한 문장으로 말할 수 있는가?
- 그 핵심 주장을 뒷받침하는 신뢰 가능한 출처가 있는가?
- 연도, 장소, 인물, 사건 순서가 서로 충돌하지 않는가?
- 원인과 결과를 너무 단순화해 거짓 인과관계로 만들고 있지 않은가?
- 논쟁 중인 해석을 확정된 사실처럼 말하고 있지 않은가?
- 영상 이미지가 시대착오나 허위 장면을 만들 위험이 큰가?
- 자료가 부족하다면 보류할 가치가 있는가, 바로 폐기해야 하는가?
