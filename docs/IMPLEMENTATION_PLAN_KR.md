2026-08-30 실제 실행 결과는 다음과 같다. 폴커크 휠은 승인 장면표와 대표 CLEAN을 통과했지만 대표 INFO가 앵커·방향·중복 문제로 보류됐다. 시티그룹 센터, 에덴 프로젝트, 후버댐은 공통 장면표 실패를 대본 계약에 반영한 뒤 다시 생성·검수했으나 대본의 시각화 가능성과 메커니즘 연결이 재차 실패했다. 템스 배리어는 교정 대본과 고정 목소리 TTS 58.92초를 통과했지만, 공식적으로 확인된 두 시각 상태만으로 18개 장면을 구성하면서 반복 상태와 불가능한 수중 가시성이 발생해 장면표가 보류됐다.

이 결과로 실패를 더 많은 AI 재호출로 해결하지 않는 정책을 확정했다. 공통 피드백은 주제·단계별 한 번만 상위 계약에 반영하며, 그 뒤의 검수도 실패하면 `needs_evidence`로 고정한다. `전체 다음 단계`는 이 상태의 주제를 다시 등록하지 않는다. 대본 검수는 예상 음성 길이 15초당 하나를 기준으로 최소 검증 시각 상태 용량을 계산해 부족한 경우 TTS와 장면표 전에 대본 축소 또는 공식 사진·도면·관찰 상태 보강을 요구한다.

품질 검증은 한 주제를 통과할 때까지 재생성하지 않는다. 각 주제를 한 번 생성·검수하고 보류 산출물과 실패 지문을 저장한 뒤, 다섯 주제에서 반복된 공통 실패만 공유 계약에 한 번 반영한다. 기본 자동 교정 횟수는 0이며, 경계 판정에만 두 번째 검수와 불일치 판정을 사용한다.

대표 자산은 `AI_PASS`와 사용자 최종 승인 `OK`를 구분한다. 벤치마크 대표 CLEAN·INFO·영상은 `AI_PASS`로 다음 샘플 단계에 진행할 수 있지만 전체 제작 잠금 해제에는 계속 `OK`가 필요하다. `/api/quality/benchmarks/advance`는 한 번 호출할 때 한 주제의 한 단계만 진행하고, `/api/quality/benchmarks/advance-all`은 다섯 주제 각각의 다음 한 단계만 직렬 큐에 등록한다. 두 API 모두 `dryRun`으로 생성 없이 다음 행동을 확인할 수 있다. 대시보드는 다섯 주제의 단계와 두 주제 이상에서 반복된 `sharedFindings`를 한 화면에 표시한다.

다음 완료 조건: `needs_evidence` 네 주제에 실제 공식 시각 근거를 보강하거나 제작 범위를 축소한 뒤 새 계약 버전으로 다시 벤치마크하고, 폴커크 INFO의 앵커·방향·중복 문제를 다른 메커니즘 INFO 사례와 함께 비교 교정한다. 다섯 주제가 모두 통과했다고 간주하지 않는다.

2026-08-31 검토 AI 보강에서는 실패 소유자를 `local_targeted_revision`, `fact_contract_revision`, `production_contract_revision`, `visual_reference_enrichment`로 분리했다. 서로 다른 검수 항목의 문장을 합쳐 제목·조건 키워드를 오판하던 분류를 항목별 판정으로 바꾸고, 저장된 검수 횟수 때문에 새 교정 1회가 소진되던 `repairCycle` 계산을 수정했다. 최신 품질 실패는 단순 총 길이 추정보다 우선하며, 총 길이만으로 대본을 축소하지 않는다.

템스 배리어는 제목과 재개방 조건을 사실 계약에서 교정한 뒤 대본 품질 점수 0.97, 오류 0건으로 통과했다. 시티그룹 센터는 대본 점수가 0.61에서 0.78까지 개선됐지만, 단일 공식 외관 사진으로 교회·면 중앙 기둥·돌출부를 동시에 입증할 수 없다는 상위 시각 계약 문제가 확인됐다. 제작 설계서 교정 AI가 불가능한 필수 가시 요소와 근거 밖 유동 분기를 제거하고 공식 외부 사진 대기로 전환했다. 에덴 프로젝트도 채광은 공식 사진으로 확인되지만 공기층의 열 손실 감소를 화면에서 입증할 공식 단면·도면이 부족해 제작 설계서 교정 후 `needs_reference`로 전환됐다. 후버댐 역시 냉각관 배치·그라우팅을 보여주는 실제 공식 단면 또는 시공 참조가 없어 같은 상태를 유지한다.

사실 검증 `visualEvidence`에는 이제 `referenceType`, `referenceSourceUrl`, `referenceMediaUrl`, `referencePage`, `referenceDescription`을 저장한다. 직접 이미지 URL은 정규화 PNG로 캐시하고, PDF는 지정된 한 페이지만 Poppler로 렌더링해 CLEAN 생성 참조로 전달한다. 본문에 도면이 있다고 적혀 있는 것만으로는 참조로 인정하지 않는다. 제작 설계서 교정 결과가 HOLD이면 작업은 실패가 아니라 `needs_reference` 완료 상태로 기록하며, 참조 대기 주제는 기존 자동 보강 큐가 다시 대본을 생성하지 않는다.

현재 완료되지 않은 범위는 명확하다. 시티그룹·에덴·후버댐은 실제 공식 시각 참조 확보가 필요하고, 폴커크는 INFO 교차 비교가 남았다. 템스 대본도 사용자 승인 전이므로 전체 벤치마크나 전체 자동화가 완료된 것으로 표시하지 않는다.

2026-08-30 밤 보강 결과, 실제 출처 확장으로 시티그룹 센터 4개, 에덴 프로젝트 3개, 후버댐 5개의 텍스트 기반 시각 근거를 확보했다. 그러나 세 주제 모두 내부 하중 경로·공기 쿠션 내부·매립 냉각관을 외부 CLEAN에서 직접 보여 달라는 제작 요구가 남아 `needs_reference`로 중단됐다. 이는 텍스트 근거와 실제 제작 참조 이미지가 다르다는 공통 실패이며, 공식 단면도·구조도·시공 사진 없이 검수 규칙을 완화하지 않는다.

템스 배리어에서는 사실 검증 근거 2개를 제작 브리프가 5개 상태로 부풀리고 대본 검수가 다시 2개뿐이라고 탈락시키는 상위 계약 충돌을 확인했다. 제작 브리프 계약 v4부터 각 상태는 사용하지 않은 시각 근거 ID 하나에 직접 연결돼야 하며, 같은 근거를 카메라·시간 설명만 바꿔 재사용하면 `unverified_state_split`으로 HOLD한다. 외부 CLEAN의 가려진 부품 요구는 자동으로 금지 목록으로 이동하고 외부 화면의 `physicalState`에서도 제거한다. 이 계약으로 템스 브리프는 `V01=정점 전 폐쇄`, `V02=썰물 재개방` 두 상태로 축소됐다. 대본은 28초·상태당 14초까지 줄었고, 검증 주장의 `또는/혹은` 조건을 단일 `보통` 조건으로 바꾸는 한정어 손실도 결정 규칙으로 차단한다.

완료 조건: 한 장을 교체했을 때 다른 장면과 영상 상태를 건드리지 않고 해당 장면만 다시 생성할 수 있어야 한다.
