# OpenShot 수동 편집

## 목적

대시보드가 장면 영상과 전체 TTS를 OpenShot 타임라인에 먼저 배치하고, 이후 편집은 사람이 직접 수행한다.

## 사용 순서

1. 제작 작업실에서 주제를 연다.
2. `편집 / 게시` 탭으로 이동한다.
3. 승인된 영상 수와 각 원본 길이를 확인한다.
4. `OpenShot에서 편집`을 누른다.
5. OpenShot에서 컷 길이, 순서, 전환, 자막, 배경음을 수정한다.
6. OpenShot의 내보내기로 최종 MP4를 만든다.

## 자동 배치 규칙

- 프로젝트: 세로 720x1280, 24fps
- 상단 트랙: 장면표 시작 시간에 맞춘 승인 영상 전체
- 하단 트랙: 전체 TTS `full.wav`
- H3 영상 원음: 음소거
- 재생 속도: 모든 영상 1배. 장면표 구간에 맞춰 시작과 끝만 트림
- INFO: H3 MP4에 이미 합성된 레이어를 사용하며 별도 정지 이미지 트랙은 만들지 않음
- 영상이 없거나 장면 구간보다 짧은 경우: 프로젝트 생성을 중단하고 해당 장면 재생성을 요구
- 편집 프로젝트: `data/projects/topic-<id>/edit/topic-<id>-edit-<revision>.osp`

`OpenShot에서 편집`은 같은 입력 리비전의 프로젝트가 있으면 기존 `.osp`를 열고, 승인 영상이나 TTS가 바뀌면 새 리비전 프로젝트를 만든다. 같은 리비전에서 OpenShot으로 저장한 수동 편집은 다시 열어도 유지된다.
