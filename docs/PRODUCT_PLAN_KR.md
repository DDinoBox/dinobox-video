# Cinematic Shorts OS 제품 계획

기준일: 2026-08-17

## 제품 정의

Cinematic Shorts OS는 영상 생성기 하나가 아니라, 설명형 쇼츠의 조사부터 편집 인계까지 관리하는 로컬 제작 운영체제다.

첫 검증 도메인은 역사지만 제품 구조는 역사에 고정하지 않는다. 메인 도메인은 역사, 공학, 과학으로 시작하며 각 도메인의 세부 주제, 출처 정책, 서사 규칙과 시각 규칙은 별도 도메인 팩으로 확장한다.

## 핵심 원칙

1. 검증되지 않은 주제는 대본으로 보내지 않는다.
2. 사람이 승인하지 않은 대본은 음성 이후 단계로 보내지 않는다.
3. 장면 수는 TTS 길이로 쪼개지 않고 물리 상태와 하중·유동 경로 변화로 결정한다.
4. 모든 산출물은 어떤 입력 버전에서 파생됐는지 기록한다.
5. 상위 산출물이 바뀌면 하위 산출물은 삭제하지 않고 `stale` 처리한다.
6. 장시간 작업은 HTTP 요청 안에서 실행하지 않고 SQLite 작업 큐에서 실행한다.
7. 실패, 취소, 재시작 뒤에도 작업 상태와 오류를 확인할 수 있어야 한다.
8. 이미지와 영상은 장면 단위로 승인하고 필요한 장면만 재생성한다.

## 현재 MVP 흐름

```text
도메인 / 세부 주제 선택
-> 후보 수집과 중복 제거
-> 기본 출처 조사
-> 필요 시 보강 검색과 2차 검증
-> PASS / HOLD / REJECT
-> 대본 생성
-> 사용자 승인
-> 고정 목소리 TTS 생성
-> 실제 길이 측정
-> 물리 상태 기반 장면표 생성과 승인
-> CLEAN 이미지 생성
-> 장면별 이미지 검수
-> 동일 CLEAN 기반 INFO 편집과 검수
-> CLEAN 기반 MiniMax H3 로컬 영상 생성 후 INFO 레이어 합성
-> MP4 검수
-> 편집 패키지와 게시문 출력
```

INFO 이미지는 원본 MD 규격의 필수 단계다. 승인된 CLEAN과 동일한 구도를 유지하며 검증된 공학 그래픽만 추가한다.

## 제품 화면

### 워크플로우

전체 제작 흐름과 각 단계의 입력, 산출물, 개발 상태를 보여준다. 전체 흐름 설명은 이 화면에만 둔다.

### 제작 작업실

메인 주제와 세부 주제를 선택하고 저장된 후보를 탐색한다. 후보 제목을 선택하면 별도의 전체 화면 작업창을 연다.

작업창 탭:

```text
개요 | 사실 검증 | 대본 | TTS | 장면표 | CLEAN 이미지 | INFO 이미지 | 영상 | 편집/게시 | 로그
```

완료 조건을 만족하지 못한 다음 탭은 잠근다. 상단에는 해당 프로젝트의 압축된 진행 상태만 표시한다.

### 백그라운드 작업

검증과 대본 생성은 대기열에 추가한 즉시 화면 제어권을 돌려준다. 사용자는 현재 단계, 진행률, 오류를 보고 작업을 취소할 수 있다. 새로고침해도 작업은 계속된다.

### 개발 계획

완료, 개발 중, 다음, 후속 단계와 완료 조건을 보여준다. 계획 문서와 화면 문구는 같은 마일스톤을 기준으로 유지한다.

## 자동화 단계

### 현재: 반자동 제작

- SQLite 후보와 산출물 관리
- Codex 기반 사실 검증과 대본 생성
- 사용자 승인 게이트
- VoxCPM2 reference voice TTS
- 물리 상태 기반 장면표와 TTS 편집 구간
- CLEAN 이미지 import와 검수 화면
- 동일 CLEAN 기반 INFO 2패스와 검수 화면
- CLEAN first/last frame ComfyUI MiniMax H3 로컬 영상 큐와 INFO 후처리
- H3 품질·균형·빠른 생성 프로필과 장면별 영상 승인

### 다음: 검수 자동화

- 주장별 근거와 출처 snapshot
- CLEAN 승인, 교체, 재생성 상태 DB 저장
- 이미지 해상도, 화면비, 누락과 중복 검사
- MP4 길이, 해상도, 코덱과 손상 검사
- 장면별 재생성

### 후속: 생성과 편집 자동화

- GPT Image 2 provider
- 이미지 생성 병렬 제한과 비용 기록
- 자막, 컷 manifest와 게시문 생성
- 편집 패키지 출력
- OpenCut Editor API가 안정된 뒤 직접 연동 검토

## 도메인 확장

각 도메인 팩은 다음을 정의한다.

```text
세부 주제 목록
우선 출처와 금지 출처
핵심 주장 분해 규칙
서사 구조
시각화 대상
시대 또는 과학적 고증 규칙
과장 금지 조건
CLEAN 이미지 규칙
영상 움직임 규칙
검수 체크리스트
```

역사는 1차 기록과 전문 해설을 구분한다. 공학과 과학은 공식 기관, 표준, 논문과 제조사 기술 자료를 출처 유형별로 구분한다.

## 완료의 정의

기능은 버튼이 보이는 것으로 완료하지 않는다. 다음 조건을 모두 만족해야 완료다.

- 실제 데이터로 성공 경로를 실행했다.
- 실패와 취소 상태를 화면에서 확인할 수 있다.
- 새로고침 또는 서버 재시작 뒤 복구된다.
- 중복 실행이 차단된다.
- 상위 산출물 변경 시 하위 산출물이 만료된다.
- 자동 테스트 또는 재현 가능한 수동 검증 기록이 있다.
