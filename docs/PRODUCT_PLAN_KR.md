# 시네마틱 쇼츠 제작 자동화 프로그램 계획

## 방향

첫 도메인은 역사로 시작한다. 공학은 정확한 물리 원리와 수치 검증 부담이 크기 때문에, 초기 MVP에서는 역사 주제로 제작 흐름과 승인 게이트를 검증한다.

프로그램의 정체성은 "영상 생성기"가 아니라 "시네마틱 설명 쇼츠 제작 파이프라인 매니저"다. 처음에는 사람이 외부 도구를 직접 사용하되, 프로그램이 단계, 산출물, 프롬프트, 검수, 파일 정렬을 관리한다. 이후 API 연결과 자동 검수를 붙여 반자동, 완전 자동으로 확장한다.

## 핵심 제품 구조

```text
주제 입력
-> 제작 규칙 자동 적용
-> 조사 메모와 출처 정리
-> 사실 검증 게이트
-> 핵심 질문 / 갈등 / 전환점 / 시각 흐름 정의
-> 대본 작성
-> 사용자 승인
-> 장면표와 키프레임 생성
-> CLEAN 이미지 프롬프트 생성
-> 외부 이미지 생성
-> CLEAN 검수
-> INFO 편집 프롬프트 생성
-> 외부 이미지 편집
-> INFO 검수
-> 4초 영상 프롬프트 생성
-> 외부 영상 생성
-> MP4 검수와 파일명 정렬
-> 편집 가이드 / 게시문 생성
```

## 사실 검증 게이트

이 프로그램의 핵심 원칙은 "검증되지 않으면 만들지 않는다"다. 재미있는 주제라도 핵심 사실이 확인되지 않으면 다음 단계로 넘어가지 않고 보류 또는 폐기한다.

판정 상태:

```text
PASS: 핵심 주장, 연도, 인물, 장소, 원인과 결과를 신뢰 가능한 자료로 확인했다.
HOLD: 흥미롭지만 핵심 근거가 부족하다. 추가 조사가 필요하다.
REJECT: 핵심 주장이 틀렸거나, 출처가 약하거나, 영상적 과장이 사실을 왜곡한다.
```

최소 통과 조건:

- 핵심 주장 1개 이상이 신뢰 가능한 자료로 확인된다.
- 중요한 연도, 인물, 장소가 서로 충돌하지 않는다.
- 영상의 주된 인과관계가 사료 또는 연구와 크게 어긋나지 않는다.
- 논쟁 중인 해석을 확정 사실처럼 말하지 않는다.
- 시각화 과정에서 만들어낼 장면이 결정적인 거짓말이 되지 않는다.

폐기된 주제는 삭제하지 않고 `manifests/REJECTED_TOPICS.md`에 기록한다.

기록 항목:

```text
주제
폐기 날짜
폐기 이유
문제가 된 주장
확인한 출처
나중에 살릴 수 있는 조건
```

## 자동화 단계

### 1단계: 수동 보조 MVP

- 프로젝트 폴더 자동 생성
- 도메인별 제작 규칙 로드
- 단계별 체크리스트 표시
- 사실 검증 게이트와 폐기 기록
- 대본, 장면표, 이미지 프롬프트, 영상 프롬프트 템플릿 생성
- 사용자가 외부 생성 도구에 복사할 수 있는 프롬프트 제공
- 현재 단계와 승인 여부 기록

### 2단계: 반자동 제작 관리

- 이미지와 영상 파일 수량 검사
- 이미지 해상도와 화면비 검사
- MP4 길이와 화면비 검사
- 콘택트시트와 대표 프레임 생성
- 파일명 번호 자동 정렬
- 누락, 중복, ID 불일치 리포트

### 3단계: 고도 반자동

- TTS 실제 길이 기반 장면 수 추천
- CLEAN/INFO 1:1 비교 검수 보조
- 편집용 컷 길이 제안
- Premiere XML, EDL 또는 컷 리스트 생성
- 게시 제목, 설명, 해시태그 생성

### 4단계: 완전 자동화 후보

- 조사 API 또는 브라우징 연동
- 이미지 생성 API 연동
- 이미지 편집 API 연동
- 영상 생성 API 연동
- TTS API 연동
- 최종 렌더링 자동화
- 업로드 전 검수 리포트 생성

## 도메인 확장 설계

공학, 역사, 과학, 비즈니스, 자연, 군사, 건축, 스포츠 등은 별도 도메인 팩으로 관리한다. 단, 사용자가 처음부터 도메인을 고르게 만들지는 않는다. 첫 MVP에서는 조선시대 역사 쇼츠를 기본값으로 두고 `history.yaml`을 자동 적용한다.

각 도메인 팩은 다음 항목을 가진다.

```text
도메인 이름
권장 이야기 구조
자료 출처 기준
시각화해야 할 핵심 요소
CLEAN 이미지 규칙
INFO 그래픽 규칙
영상 움직임 규칙
검수 체크리스트
금지 조건
```

## 역사 도메인 MVP

역사 주제는 다음 네 문장으로 시작한다.

1. 핵심 질문: 왜 이 사건이나 선택이 중요했는가?
2. 핵심 갈등: 어떤 세력, 조건, 제약이 충돌했는가?
3. 보이는 흐름: 사람, 군대, 물자, 돈, 정보, 권력, 영토 중 무엇이 이동했는가?
4. 전환점: 어느 결정, 장소, 기술, 실수, 우연이 결과를 바꾸었는가?

권장 서사:

```text
불안정한 배경
-> 충돌하는 이해관계
-> 실패 가능성 확대
-> 결정적 선택 또는 사건
-> 흐름의 변화
-> 결과와 파급
-> 다른 해석 또는 한계
-> 짧은 결론
```
