장면표

AI가 승인 대본, 사실 검증과 실제 TTS 길이를 바탕으로 서로 다른 장면을 설계하는 화면
대기
TTS 생성 후 장면표를 만들 수 있습니다.
CLEAN 검수 불러오는 중

INFO 검수 불러오는 중
모든 CLEAN을 승인하면 정확한 글꼴과 그래픽으로 INFO 이미지를 만들 수 있습니다.

영상

MiniMax H3 로컬 모델로 CLEAN 영상을 만든 뒤 정확한 INFO 그래픽을 합성하고 검수하는 화면
대기
CLEAN 이미지가 준비되면 영상 프롬프트와 MP4 상태를 확인할 수 있습니다.

편집 / 게시

대기
