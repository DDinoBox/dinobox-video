쇼츠 주제 찾기

메인 주제를 누르면 세부 주제가 그 분야에 맞게 바뀌고, 후보는 리스트로 비교
1 메인 주제 먼저 하나 선택
2 세부 주제 메인 주제에 맞춰 표시

후보 주제 리스트

10개 이상 비교할 때는 카드보다 리스트가 낫고, 점수와 상태를 한 번에 보기 쉬움
후보 주제 상태 검증 시각 의외 길이 위험 액션
아직 생성된 후보 주제가 없습니다. 메인 주제를 고르면 저장된 후보가 보이고, 세부 주제를 고르면 그 범위로 좁혀집니다.
주제 더 찾기 선택한 범위에 새 후보를 추가
찾을 개수

대본 작업

선택된 주제 하나의 검증 결과, 핵심 구조, 대본 초안, 승인 상태를 관리

선택된 후보

쇼츠 주제 리스트에서 검증 또는 대본을 실행할 후보를 선택하세요.

사실 검증

아직 검증 결과가 없습니다.

핵심 구조

PASS 후 대본을 생성하면 표시됩니다.

제작용 대본

아직 생성된 대본이 없습니다.

TTS용 텍스트

아직 생성된 TTS 텍스트가 없습니다.

TTS / 목소리

고정 목소리 프리셋, 로컬 엔진 준비 상태, 장면별 음성 길이 관리

목소리 프리셋

목소리 프리셋을 불러오는 중입니다.

로컬 준비 상태

확인 전상태 새로고침을 누르면 표시됩니다.

현재 대본 TTS 계획

대본 작업에서 주제를 선택하면 이곳에 TTS 계획이 표시됩니다.

준비 전
아직 준비된 TTS 세그먼트가 없습니다.

장면표

승인 대본과 실제 TTS 길이를 기준으로 장면 ID와 키프레임을 나누는 화면
S01A변방 봉수대에 위기 신호 발생대기
S02A산 능선을 따라 신호 이동대기
S03A한양 봉수대로 정보 도착대기
S04A날씨와 관리 상태라는 한계대기

프롬프트

CLEAN, INFO, 4초 영상 프롬프트를 단계별로 생성하고 저장하는 화면
CLEAN글자 없는 원본 이미지 프롬프트대기
INFO경로선과 짧은 라벨 추가 프롬프트대기
VIDEOCLEAN에서 INFO가 조립되는 영상 프롬프트대기
게시문제목, 설명, 해시태그 초안대기

자산 검수

CLEAN, INFO, MP4 파일 수량과 대응 관계를 확인하는 화면
CLEAN 이미지0개 / 예상 12~16개대기
INFO 이미지0개 / CLEAN과 1:1 필요대기
MP40개 / 4초 원본 클립대기
정렬파일명 번호와 ID 검수대기

편집/게시

TTS 길이, 컷 길이, 제목과 설명을 관리하는 마지막 화면
TTS실제 길이 미입력대기
컷 리스트장면별 사용 구간 미생성대기
제목추천 제목 1개와 대체 3개대기
설명요약, 단순화 고지, 해시태그대기

개발 로드맵

수동에서 완전 자동화까지

1단계: 수동 보조

  • 대시보드
  • 프로젝트 폴더 생성
  • 도메인 템플릿
  • 프롬프트 파일 생성

2단계: 반자동 관리

  • 이미지 수량 검사
  • 화면비 검사
  • MP4 길이 검사
  • 파일명 정렬

3단계: 검수 보조

  • 콘택트시트 생성
  • 대표 프레임 추출
  • CLEAN/INFO 비교
  • 편집 컷 리스트

4단계: 자동 생성

  • TTS API
  • 이미지 API
  • 영상 API
  • 최종 렌더링

자동화는 한번에 끝까지 붙이지 않고, 실패 비용이 낮은 파일 관리와 검수부터 시작합니다. 생성 API 연결은 워크플로우와 산출물 규격이 안정된 뒤 붙이는 편이 좋습니다.
